# test_spp

Простейший проект «Hello world» на JavaScript.

## Запуск

```bash
node main.js
node name.js
```

## Назначение ветвей

- `main` — стабильная ветка, готовая к выпуску.
- `bugfix/console-output` — исправление ошибки: вызовы `console.log` вместо `confirm.log`.
- `feature/greeting` — доработка приветствия: текст `Hello world`.
- `docs/readme` — документация проекта.

Проект используется для лабораторной работы по GitHub Flow.
